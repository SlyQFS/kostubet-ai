# KostubetAI 2.0

Telegram ИИ-бот с локальной базой знаний (Knowledge Base), мета-памятью о собеседниках и переключением моделей на лету.

## Возможности

- **Триггеры в группах**: бот отвечает только на `@упоминание` и reply к своим сообщениям. Изоляция памяти по форум-топикам (`thread_id`). Чужие слэш-команды игнорируются молча.
- **ЛС — только админка**: `/model` открывает inline-кнопки смены модели (переключение действует сразу на все чаты). Обычным пользователям — заглушка.
- **Мета-память (`user_states`)**: о каждом собеседнике хранится блок `<user:@nick id=123 goal="..." current="...">` — цель и текущий прогресс. Модель сама обновляет теги в конце ответа; бот их извлекает, сохраняет и вырезает перед отправкой.
- **Скользящее окно истории** по каждому чату/топику (`MESSAGE_WINDOW_TOKENS`, эвристика ~3 символа/токен). Общий флуд не хранится.
- **База знаний (Knowledge Base)**: карточки `knowledge/*.json`. Подбор карточек — семантический (fastembed, ONNX, multilingual-e5-small, скачивается в `data/models/` при первом запуске) + поиск по корням слов без окончаний (русский Snowball-стемминг) и точным ключевым словам/сленгу ("бл", "edl", "adb"). Без эмбеддера бот продолжает надёжно работать на стемминге и ключевых словах.
- **Прогрессивный вывод**: плейсхолдер «💬 Думаю…» + Typing-индикация + редактирование по мере стриминга; финал делится на части по 3900 символов.
- **Очередь и лимиты**: семафор параллельных запросов, пейсер 50 мс, per-user rate limit, retry с exponential backoff на 429/5xx.
- **OpenAI-совместимый LLM API**: любой провайдер через `LLM_BASE_URL`.

## Запуск

```bash
cp .env.example .env   # заполнить BOT_TOKEN, LLM_API_KEY, LLM_MODELS, ADMINS
cargo run --release
```

Через Docker:

```bash
docker compose up -d --build
```

## Формат базы знаний

`knowledge/имя-карточки.json` (поддерживаются как одиночные карточки, так и JSON-массивы):

```json
{
  "title": "Разблокировка загрузчика (Android 13+ Qualcomm)",
  "keys": ["bootloader", "загрузчик", "разблокировка", "разлочить", "fastboot", "бл", "flashing unlock"],
  "content": "Текст руководства, который попадёт в системный промпт при совпадении."
}
```

Поиск учитывает формы слов без окончаний (например, «проблема с загрузчиком» найдет карточку по ключу «загрузчик»), короткий сленг и векторную семантическую близость.

## Переменные окружения

См. [.env.example](.env.example). Ключевые:

| Переменная | Смысл |
|---|---|
| `BOT_TOKEN` | токен бота |
| `LLM_BASE_URL` / `LLM_API_KEY` | эндпоинт и ключ OpenAI-совместимого API |
| `LLM_MODELS` | модели через запятую; первая — активная |
| `ADMINS` | id админов (доступ к ЛС-админке) |
| `ALLOWED_CHATS` / `ALLOWED_THREADS` | вайтлист групп/топиков (пусто = все) |
| `MESSAGE_WINDOW_TOKENS` | окно истории чата, токенов |
| `KNOWLEDGE_DIR` | путь к папке с карточками базы знаний (по умолчанию `knowledge`) |
| `KNOWLEDGE_TOP_N` | сколько карточек максимум подтягивать в промпт |
| `KNOWLEDGE_THRESHOLD` | порог cosine-близости для карточек |

## Структура

```
src/
  bot/        router, админка (/model), групповые хендлеры, очередь, rate limit
  llm/        клиент с ретраями и SSE-стримом, состояние активной модели, сборка промпта
  knowledge/  загрузчик карточек базы знаний, матчер (fastembed + стемминг + ключи)
  storage/    sqlx/sqlite: messages (скользящее окно), user_states (мета-блоки)
  utils/      санитайзер <user:...> тегов, split_telegram
knowledge/    карточки базы знаний (Android 13+, Qualcomm, Root, Flashing, A/B)
migrations/   SQL-миграции (грузятся рантаймом из ./migrations)
```
