# KostubetAI

Телеграм-бот ИИ-ответчик на Rust с умной памятью и жёстким лимитом базы в 1 ГБ.

Работает с любой OpenAI-совместимой моделью (OpenAI, OpenRouter, Ollama, vLLM, LM Studio и т.д.).

## Как устроена память

Память **строго по пользователям**, без пересказов и «лишних» знаний:

- Для каждого пользователя бот хранит дословную историю его последних сообщений
  и своих ответов — в пределах **5000 токенов** (`USER_MEMORY_TOKENS`).
  Как только история выходит за лимит, самые старые сообщения удаляются.
- Ничего сверх этого не запоминается: нет конспектов, нет извлечённых фактов —
  только живой контекст беседы.
- Токены считаются по эвристике «~3 символа на токен» (без словаря токенизатора),
  для русского и английского текста оценка идёт с запасом.

### Гайды

В бота можно загружать **гайды** — текстовые документы, на которые он опирается,
когда вопрос релевантен:

- Пришли боту текстовый файл (`.txt`, `.md`, `.csv`, `.json`, `.log`, `.yaml`, …),
  до 5 МБ; название гайда — первая строка подписи к файлу (или имя файла).
- Либо ответь командой `/guide_add Название` на сообщение с текстом гайда.
- Гайд нарезается на фрагменты по ~1200 символов. На каждое сообщение пользователя
  ищутся фрагменты, релевантные ему по значимым словам, и лучшие (до ~4000 символов)
  подмешиваются в контекст модели. Нерелевантные гайды на ответы не влияют.

### Лимит 1 ГБ

Общий размер базы SQLite (файл + WAL-журнал) ограничен `MEMORY_LIMIT_MB` (по умолчанию 1024).
При достижении 95% лимита запускается поэтапная чистка — от бережной к жёсткой:

1. история всех пользователей урезается до ~1000 токенов;
2. история всех урезается до ~100 токенов;
3. удаляются истории всех, кроме 500 самых недавно активных;
4. удаляются самые старые гайды (до 50 за проход).

За счёт персональных лимитов до этапа чистки в реальной работе дело почти
никогда не доходит: 5000 токенов истории ≈ 15 КБ на пользователя.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/help` | справка |
| `/reset` | очистить память бота о тебе |
| `/memory` | статистика: твоя память и размер базы |
| `/guides` | список гайдов |
| `/guide_add <название>` | добавить гайд (ответом на сообщение с текстом) |
| `/guide_del <название или id>` | удалить гайд |

В группах бот отвечает при упоминании `@имя_бота` или в ответ на его сообщение.

## Запуск (Docker)

Единственный способ деплоя — Docker: образ собирается из исходников, никакой
Rust-инструментарий на сервере не нужен.

```bash
cp .env.example .env   # заполнить TELEGRAM_BOT_TOKEN и настройки модели
docker compose up -d --build
```

Токен бота выдаёт [@BotFather](https://t.me/BotFather).

- База SQLite хранится в именованном томе `kostubetai-data` и переживает
  пересборки и обновления контейнера.
- Контейнер запускается от не-root пользователя и корректно останавливается
  по SIGTERM (`docker stop`).
- Логи: `docker compose logs -f`.
- Обновление до новой версии: `git pull && docker compose up -d --build`.

### Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — обязательна | токен от @BotFather |
| `LLM_API_KEY` | — | ключ API (пусто — для локальных серверов без авторизации) |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | любой OpenAI-совместимый API |
| `LLM_MODEL` | `gpt-4o-mini` | название модели |
| `DATABASE_PATH` | `data/memory.db` | путь к базе SQLite |
| `MEMORY_LIMIT_MB` | `1024` | жёсткий лимит размера базы |
| `USER_MEMORY_TOKENS` | `5000` | лимит памяти на пользователя |
| `ADMIN_USER_IDS` | пусто | id админов через запятую; только они управляют гайдами (пусто — все) |
| `MAX_REPLY_TOKENS` | `1500` | максимум токенов в ответе |
| `LLM_TEMPERATURE` | `0.7` | температура генерации |
| `RUST_LOG` | `kostubetai=info,teloxide=warn` | уровень логов |

Примеры `LLM_BASE_URL` / `LLM_MODEL`:
- OpenAI: `https://api.openai.com/v1` + `gpt-4o-mini`
- OpenRouter: `https://openrouter.ai/api/v1` + любая модель каталога
- Ollama: `http://localhost:11434/v1` + например `qwen2.5:7b`

### Локальная разработка

Для запуска без Docker нужен Rust:

```bash
cargo run --release
```

## Тесты

```bash
cargo test
```

Покрывают: бюджет токенов и обрезку истории, жизненный цикл гайдов и поиск
релевантных фрагментов, поэтапную чистку базы при превышении лимита,
разбиение длинных ответов под лимит Telegram, разбор команд.
